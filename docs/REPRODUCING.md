# Reproducing figures and building the paper

The seven graph PDFs can be regenerated from the supplied result data without running a language model. The two schematic diagrams are drawn by TikZ when the manuscript compiles.

## Python environment

The figure workflow was tested with Python 3.12.13, Matplotlib 3.10.7, and NumPy 2.5.3. From the repository root:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements/figures.txt
.venv/bin/python scripts/manifest.py
.venv/bin/python scripts/plot_figures.py
```

The manifest command checks the files under `code/`, `data/`, `docs/`, `requirements/`, and `scripts/`, plus the README and `.gitignore`. After an intentional edit, refresh it with `python scripts/manifest.py --write`.

The plot command writes seven PDFs to `build/figures/`, PNG previews to `build/checks/`, and `build/checks/figure_data_manifest.json`. Successful completion prints `verified frozen manuscript coordinates for all seven figures`. This means the plotted coordinates agree with both `code/plotting_reference.py` and `data/figure_values.json`. It does not rerun the experiments or recompute their statistical estimates. The script accepts `--output-root PATH` to place the output elsewhere.

The data guide explains each input file. The four-bar steering and four-model comparison plots retain numeric constants from the original plotting code; they are not calculated from the separate eleven-arm steering campaign.

## Compile the manuscript

Install a TeX distribution containing XeLaTeX and the packages used in `paper/main.tex`, then run:

```bash
python scripts/build_paper.py
```

This copies the manuscript inputs into a temporary build directory, runs XeLaTeX three times, and writes `artifacts/paper.pdf`. Logs and the build report are saved under `build/`. The paper uses filename-based TeX Gyre Termes font loading where available, with a Times New Roman fallback for the preparation machine.

Tectonic is also supported:

```bash
python scripts/build_paper.py --engine tectonic
```

For an offline Tectonic cache, use `--only-cached`. If a standard TeX package is missing from that cache, `--support-file /path/to/package.sty` copies that file into the temporary build directory. This is a local build option; the arXiv source package relies on its TeX distribution for standard packages.

## Make the arXiv ZIP

```bash
python scripts/package_arxiv.py
```

The archive `artifacts/arxiv-source.zip` contains `main.tex`, `appendix.tex`, `main.bbl`, `00README.json`, figure PDFs, and a compact code/data supplement under `anc/`. It excludes generated outputs, model weights, activation dumps, repository metadata, and the submission-form Markdown. `artifacts/package-report.json` records the archive hash and all included file hashes. The archive selects XeLaTeX through `00README.json`; inspect the PDF generated by arXiv before submitting.
